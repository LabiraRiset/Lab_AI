# Prompt Lab

Microsite satu halaman untuk praktik “AI, Media Digital, dan Generasi Muda”.

## Penggunaan

Buka `dist/index.html` di browser atau unggah folder `dist` ke layanan hosting statis.

Fitur utama: prompt siap salin, tautan ke aplikasi AI, timer praktik, filter aktivitas, dan lembar kerja kelompok yang dapat disalin ke Padlet atau Google Forms.
